# MindHaven Voice AI Assistant

MindHaven Voice AI is a lightweight emotional support tool that allows users to communicate with an AI assistant through both **voice and text**. This project demonstrates real-world AI skills across NLP, speech recognition, and emotional wellness technology.

---

## 🎧 Features
- 🎤 Voice input (Speech → Text)
- 💬 AI response (Text → Emotion-aware reply)
- 🔊 Optional voice output (AI speaking back)
- 😀 Mood detection (sad, angry, stressed, calm)
- 🧘 Mental-wellbeing guidance (sleep tips, breathing, affirmations)

---

## 🛠 Tech Stack
- Python
- SpeechRecognition (voice input)
- gTTS / pyttsx3 (voice output)
- Transformers (sentiment)
- OpenAI / HuggingFace LLM
